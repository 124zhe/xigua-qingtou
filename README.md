# 🍉 轻投 · xigua-qingtou

**整理一次简历，少填几遍网申。**

轻投是一款面向中文招聘网申的 Chrome / Microsoft Edge 扩展。把简历整理为可复用资料，在招聘网页中识别字段、预览对应内容，再填写选中的项目。遇到不确定的经历对应关系，会按简历顺序补空并标黄，方便你核对。

当前版本：**0.5.11** · Manifest V3 · 本地解析 · MIT 开源

[下载可安装 ZIP](downloads/xigua-qingtou-0.5.11.zip?raw=true) · [详细使用指南](docs/USAGE.md) · [隐私说明](docs/PRIVACY.md) · [兼容范围](docs/COMPATIBILITY.md)

## 能做什么

- **导入简历**：在本地读取 PDF、DOCX、TXT，或粘贴简历文字；核对提取结果后再保存。
- **管理资料**：基本资料、教育、实习与工作、项目、技能、获奖及其他自定义模块。
- **添加自己的字段**：每段经历支持独立的字段名称、内容和其他叫法，例如排名、研究成果、项目链接。
- **预览再填写**：字段按网页可见顺序展示；保留官网已有值，缺资料可回到资料页补充。
- **尽量补空，疑点标黄**：优先匹配已有学校、公司、项目及日期；无法唯一对应时按简历顺序选择剩余记录。明确冲突和不支持的控件会提示核对。
- **本地备份和记录**：导入／导出资料备份，手动记录投递情况，导出不含填写内容的诊断报告。

轻投不代替你提交申请，也不保证所有招聘网站和特殊控件均受支持。请在官网提交前检查内容。

## 安装（不需要编程环境）

1. 点击上方 **下载可安装 ZIP** 并解压到固定位置。不要直接从压缩包打开，也不要放进会自动清理的临时目录。
2. 打开扩展管理页：
   - Edge：在地址栏输入 `edge://extensions/`
   - Chrome：在地址栏输入 `chrome://extensions/`
3. 打开 **开发人员模式／开发者模式**。
4. 点击 **加载解压缩的扩展／加载已解压的扩展程序**。
5. 选择解压后的 **`xigua-qingtou/extension` 文件夹**，其中应直接包含 `manifest.json`。
6. 在浏览器工具栏的扩展菜单中固定“轻投”。

如果使用 GitHub 的 **Code → Download ZIP** 下载源码，请选择解压后的 `xigua-qingtou-main/extension`。这两种方式都不需要 Node.js、Python、服务器、账号注册或 API Key。仅面向支持加载本地扩展的桌面 Chrome / Edge；单位管理的浏览器可能限制开发者模式。

## 第一次使用

1. 点击工具栏里的轻投 → **编辑网申资料**。
2. 选择 **上传简历并解析**，或手动填写。核对教育、实习和项目是否分段正确，再确认导入。
3. 补充官网常问的内容。排名等字段可以放在对应经历的“自定义字段”里；获奖可以在“技能与补充”中整理为逐条记录。
4. 先点击 **先在练习表单试一下** 熟悉操作；示例内容均为虚构，不能当作自己的简历。
5. 打开招聘表单，展开需要填写的经历；点击轻投 → **识别当前页面**。
6. 在右侧预览核对来源和标黄项，勾选需要填写的字段，点击 **填写所选项**。附件需要单独勾选授权。
7. 检查官网中的值、下拉选项、日期和校验提示，最后由你在官网保存或提交。

更详细的补充资料、别名、日期、备份和排错步骤见 [使用指南](docs/USAGE.md)。

## 更新

先在资料页 **导出备份**。把新版文件放到原来的固定目录，在扩展管理页点击轻投的 **重新加载**，再回招聘页点击工具栏里的 **更新当前页预览**。确认“已安装扩展”和“当前页预览”版本一致。

通常无需卸载扩展或刷新未保存的网申页面。若改用新的目录或浏览器，资料可能属于不同扩展存储；请先备份，在新安装中导入并核对后再处理旧安装。

## 资料与权限

简历解析和资料保存均在本地进行。本项目没有后端、第三方解析服务或分析埋点；不包含开发者的真实简历、联系方式、浏览器资料或密钥。

扩展使用 `storage` 保存资料，使用 `activeTab` 和 `scripting` 在你主动操作的页面识别／填写。点击填写后，内容会进入招聘网站，网站可能即时收集或自动保存；“本地存储”不等于填写后仍不离开浏览器。备份可能含简历正文、联系方式和附件，请自行妥善保管。详见 [隐私说明](docs/PRIVACY.md)。

## 开发与验证

产品源码在 `extension/`，无需构建即可加载。开发检查需要 Node.js 22 或更新版本；打包脚本需要 Python 3.10 或更新版本。

```bash
git clone https://github.com/124zhe/xigua-qingtou.git
cd xigua-qingtou
node scripts/check.mjs
node scripts/test.mjs
python scripts/package.py
```

公开仓库提供可离线运行的语义、资料和诊断测试。完整发布验证还包含隔离浏览器与网站公开组件；网站组件包及含环境路径的内部日志不随源码发布。公开检查不能替代真实组件或在线验证，范围见 [验证说明](docs/VALIDATION.md)。

欢迎提交适配问题和 PR。报告问题时请先隐藏姓名、联系方式、证件号码及简历内容，优先提供脱敏诊断和使用虚构资料的最小示例。见 [贡献指南](CONTRIBUTING.md)。
