# 兼容范围

轻投优先使用通用标签、经历分段、已有内容匹配和控件驱动。仅在结构确有差异时使用专用适配；不以用户姓名、学校或截图顺序硬编码资料。

已覆盖普通输入框、文本域、原生单选、部分搜索下拉、年月拆分、日期与地区选择，以及常见 React / Vue 招聘组件。已做隔离验证的范围包括京东、同花顺、网易、字节、Moka、华为、百度、携程、51job、Hotjob 和东航的部分表单或公开组件。

这不是整站兼容承诺。招聘网站可能改版，不同岗位、账号阶段和表单配置也可能不同。隔离组件测试不代表真实账号、服务器保存或投递已经验证。

## 对应与保留

- 预览保持网页顺序，附件留在原位置；筛选只隐藏行。
- 已有学校、公司、项目、奖项及日期优先用于整段对应，并保留官网已有值。
- 无法唯一对应时按剩余简历记录的顺序补空并标黄，明确网站排序规则仍优先。
- 缺资料不借用其他记录；日期冲突、段界冲突、控件拒绝或重要人工改动需要核对。
- 学历与学位、学院与任职部门、本人和紧急联系人分别处理。
- 多选、复杂搜索、未知日期范围和特殊控件可能需要手动操作。

## 0.5.11 / 0.5.10

通用字段标题查找支持深层单控件包装和 camelCase 栏目样式，仍排除导航、其他输入框的标签以及相互冲突的显式标题。

京东基本信息使用公开原始 React / Ant 组件验证：Input、Select 和 Cascader。籍贯按唯一完整省市路径选择，等待异步城市；证件类型与号码在同组唯一时核对，类型冲突或缺失需要确认。已有内容保留，缺资料不推测。

校园经历优先使用同名自定义模块；否则使用项目资料整段补空并标黄。已有活动名称和日期用于对应，重复名称按剩余记录顺序分配；明确模块、字段或日期冲突不会跨活动借用资料。

京东起止时间由两个独立 Ant v3 DatePicker 组成，使用原始回调写入并核对时间戳模型、另一端日期、组件错误和重挂载。此处不代表支持原生 Ant RangePicker。混合教育场景只验证记录及日期分离，学校/专业/学历使用简化文本字段，不表示验证了京东学校搜索。

## 0.5.9

修复获奖说明被字数计数 `0/300` 抢占标题，以及普通样式获奖栏目漏识别。奖项名称和说明按同一记录对应；重复名称、未知名称与无锚点按顺序补空并提示。明确日期冲突或已被使用的唯一名称／日期记录不会借入另一奖项的说明。字段重挂载需核对原容器、模块和含义。
