# 兼容范围

轻投优先使用通用标签、经历分段、已有内容匹配和控件驱动。仅在结构确有差异时使用专用适配；不以用户姓名、学校或截图顺序硬编码资料。

已覆盖普通输入框、文本域、原生单选、部分搜索下拉、年月拆分、日期与地区选择，以及常见 React / Vue 招聘组件。已做隔离验证的范围包括同花顺、网易、字节、Moka、华为、百度、携程、51job、Hotjob 和东航的部分表单或公开组件。

这不是整站兼容承诺。招聘网站可能改版，不同岗位、账号阶段和表单配置也可能不同。隔离组件测试不代表真实账号、服务器保存或投递已经验证。

## 对应与保留

- 预览保持网页顺序，附件留在原位置；筛选只隐藏行。
- 已有学校、公司、项目、奖项及日期优先用于整段对应，并保留官网已有值。
- 无法唯一对应时按剩余简历记录的顺序补空并标黄，明确网站排序规则仍优先。
- 缺资料不借用其他记录；日期冲突、段界冲突、控件拒绝或重要人工改动需要核对。
- 学历与学位、学院与任职部门、本人和紧急联系人分别处理。
- 多选、复杂搜索、未知日期范围和特殊控件可能需要手动操作。
