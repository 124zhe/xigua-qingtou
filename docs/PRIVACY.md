# 隐私与数据范围

轻投的简历解析在浏览器内完成，资料保存在当前扩展的 `chrome.storage.local`。独立练习页面在非扩展环境可能使用该页面的 localStorage，两者不是同一份存储。项目没有账号服务、云端简历数据库、远程解析或分析埋点。

## 权限

| 权限 | 用途 |
| --- | --- |
| storage | 本地保存资料、设置、附件及投递记录 |
| activeTab | 在你主动使用扩展时访问当前页面 |
| scripting | 注入字段识别、预览及填写逻辑 |

Manifest 不申请全站永久访问或读取浏览历史的权限。扩展页面使用本地脚本与依赖；内容脚本在招聘网页内执行必要的表单操作。

## 何时内容会离开本地

你点击填写后，资料进入当前招聘网站。即使尚未点击提交，该网站也可能通过页面脚本、实时校验或自动保存收集字段值。单独授权附件上传后，文件由目标网站接收。轻投无法控制第三方网站如何处理这些信息。

备份文件可能包含完整个人资料、投递记录及简历附件；备份不是脱敏诊断。不要公开分享或放入 Git 仓库。本地存储也不意味着已经加密或具备备份保障。

## 诊断与反馈

“导出诊断”使用固定的状态、类型和计数等信息，不导出填写值、简历原文、网页地址或自定义问题原文。报告不会自动上传。分享前仍建议检查文件；截图和复现步骤应自行脱敏。

## 本公开仓库

源码、示例和公开测试不包含开发者的真实简历、联系方式、证件、浏览器用户资料、私人备份、截图或认证凭据。示例与测试数据为虚构内容，不能用于真实投递。

发布采用文件白名单、个人信息与密钥模式扫描、源码哈希及 ZIP 内容检查。工作目录和开发历史不会直接整体推送到仓库。
