# 更新记录

## 0.5.11 · 2026-10-30 GitHub 发布

本版同步 0.5.10 和 0.5.11 的已完成修复，扩展版本为 0.5.11。

- 京东校园经历识别活动名称、担任职务、经历描述与起止日期，保持整段资料一致。
- 有校园自定义模块时优先使用；否则项目资料补填会标黄提醒栏目归属。已有内容、缺资料和重复经历分别处理。
- 起止日期通过原始日历回调填写，核对另一端、严格先后、非法日期、错误样式、人工介入及两端单独或整段重挂载。
- 月份资料遵循既有补日设置，并显示约定；缺失值和“至今”不编造成具体日期。
- 同步 0.5.10 的籍贯、证件号码、所在城市等深层标题识别、省市级联、证件类型核对和动态页面保护。

验证结果见 [VALIDATION.md](VALIDATION.md)。京东使用公开原始组件与虚构资料离线验证，没有执行真实账号保存或投递。

更新时将文件放回原固定目录，重新加载扩展，再点击“更新当前页预览”。确认已安装和当前页版本均为 0.5.11；换目录前先导出本地资料备份。
