# 使用指南

## 1. 整理自己的资料

从工具栏点击“编辑网申资料”。可以手动输入，也可以选择“上传简历并解析”或“粘贴简历文本”。支持 PDF、DOCX、TXT；文件不超过 10 MB，PDF 不超过 20 页。不支持旧版 DOC、加密 PDF 或扫描图片的 OCR，请先转为可提取文字的格式。

导入后先检查原文、分段、姓名、学校、公司、项目和日期，再选择需要合并的部分。解析不能保证完整准确，复杂排版可能漏项。编辑器会自动保存本地资料；“导出备份”可保存副本。

## 2. 教育、工作与项目

每段经历单独保存。学校／学院、专业、学历／学位，以及公司／部门／岗位是不同字段，请按事实分别填写。经历顺序可以作为网页无法确定对应关系时的默认顺序；官网明确要求学历或时间排序时，以已支持的官网规则为准。

在每张经历卡片底部的“自定义字段”点击“添加字段”，填写名称和内容，例如“专业排名”“项目链接”。如果网页叫法不同，可填写“其他叫法”。字段只属于当前这段经历，不会自动借用另一所学校或公司的答案。内置字段有值时优先使用，冲突会标黄。

## 3. 获奖及其他自定义模块

在“技能与补充”填写奖励荣誉原文后，可点击“查看／整理逐条获奖记录”。逐条核对奖项名称、级别、时间、颁奖单位和获奖说明。网页将奖项拆为多行时，这些记录可分别填入。没有提供的时间或说明不会凭空生成。

“自定义模块”可整理语言能力、证书等重复记录。为模块和字段设置明确名称及其他叫法，有助于不同网站识别。普通“说明”只有结合明确栏目才能确定含义；不能把同名字段当作所有模块通用的答案。

## 4. 在招聘页面填写

打开需要填写的表单，先展开或添加你需要的经历行，再从轻投工具栏点击“识别当前页面”。扩展不会自动替你创建所有官网记录。

右侧预览按网页顺序展示。你可以定位到网页、调整资料对应、切换“全部／待处理”，或点击“补充此项”。补充后“保存并返回招聘页”，再检查更新后的预览并点击“填写所选项”。

- **已有值**：默认保留。不要把“已保留”理解为扩展已经核验它正确。
- **标黄**：使用了按顺序推测的记录或发现内容差异，填写后仍需检查整段归属。
- **缺资料**：在对应记录中补充，再更新预览；不会借用别段的值。
- **需手动／待指定**：可能是控件不受支持、字段含义不明确、日期冲突或需要独立回答，请按提示处理。
- **附件**：核对文件后单独勾选；上传由招聘网站处理。

官网重建字段、增删经历或你人工改动内容后，可能需要重新识别。填写过程中检测到重要字段变化会停止后续操作，以免沿用旧对应关系。

## 5. 日期

资料可保存年月，也可补充到日。完整日期优先。只有年月、但网站要求年月日时，默认按当月 1 日填写并提示；你可以在资料页更改这一约定。该日期是填写约定，不是自动推断出的真实日期。对于明确冲突、非法日期或不支持的“至今”控件，按提示核对。

## 6. 备份、迁移与更新

在资料页点击“导出备份”，保存 JSON 到私人目录；迁移后使用“导入备份”并核对资料、附件及投递记录。不要把备份提交到 GitHub Issue 或代码仓库。

更新源码后，在扩展管理页重新加载，再在招聘页点“更新当前页预览”。版本状态只比较本机扩展和当前页脚本，不查询商店更新。更换目录、浏览器或卸载扩展前先备份；浏览器存储不是跨设备云同步。

## 7. 常见问题

**加载时报找不到 manifest？** 选择直接包含 `manifest.json` 的 `extension` 目录，而不是 ZIP 或仓库顶层。

**某个字段认不出来？** 先展开表单、重新识别；检查是否有资料、明确名称和正确经历。如果仍失败，导出脱敏诊断，并用虚构内容提供网站结构或截图。

**显示已填写，但官网仍报错？** 检查是否真正选择了下拉项、日期是否完整、是否还有必填项。扩展读回验证不等同于服务器保存成功。

**扫描版简历读不到？** 当前不包含 OCR。可粘贴文字，或使用文字版 PDF、DOCX、TXT。

**要填写姓名、证件等敏感内容吗？** 只保存你愿意用于网申的资料。提交前由你检查；不要填写来源不明或需要猜测的个人事实。
