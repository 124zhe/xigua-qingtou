# 发布验证

版本：0.5.11。公开发布前重新执行完整门禁；本文件的最终结果与 `release-manifest.json` 一起记录。

2026-10-30 发布前完整门禁：**72 套、1,360 项全部通过**。所有报告本轮重新生成，产品源码及共享测试依赖前后哈希一致。另有公开仓库 6 套、389 项纯 Node 测试通过。

完整门禁覆盖字段语义、控件回调、已有值保留、缺资料、重复记录、歧义／冲突、人工改动、动态重挂载、错误反馈、资料编辑、导入与备份、预览顺序及脱敏诊断。

本版比 0.5.9 新增四套回归：

- 京东基本信息 19 项：公开原始 React 输入框、下拉及省市级联，检查真实表单回调、异步地区和证件类型冲突等。
- 通用深层标签 12 项：受控 DOM，验证附近标题、重复字段、显式标签优先、冲突及错误提示隔离。
- 京东记录 25 项：公开原始 GEq+、AvF8、E7Sx、Nmnl、SYOc 组件，检查校园/项目/实习记录、真实日期时间戳、职务回调、模块优先、已有内容、缺项、重复记录、原始新增按钮与人工修改。
- 校园与日期边界 18 项：其中十项使用原始组件；一项在原始夹具中受控替换另一端输入框；六项使用无京东类名的受控 DOM；最后一项检查脚本错误和网络。覆盖日期冲突、原始错误反馈、重挂载、模块歧义、栏目保护和日期对边界。

京东公开静态资源来自 campus.jd.com 使用的 20260902001311 资源版本。夹具关闭应用入口、替换 Redux 注入与字典请求，保留原始渲染和回调；全部网络阻断并使用虚构资料。没有连接日常浏览器、招聘账号或执行真实保存、投递。学校搜索组件未在本次校园日期场景验证；两个独立日历的验证不代表原生 Ant RangePicker 支持。

其他测试分别使用公开组件或受控结构；例如同花顺获奖使用公开原始 Vue / Element 组件，检查实际 name / description 模型和必填回调。

公开仓库中的 `node scripts/test.mjs` 提供可重复运行的纯 Node 测试；它是完整门禁的子集，不等于完整浏览器验证。招聘网站组件包、私人环境路径和内部日志未在本仓库重新分发。欢迎使用虚构表单补充公开回归。

发布源码与已测产品逐文件核对，安装包检查资源引用、语法、第三方许可证、ZIP CRC 和逐文件哈希。公开源码仍可能有缺陷，未知网站需要独立验证。
